# 손지헌 포트폴리오

데이터 기반 서비스 기획자 손지헌의 개인 포트폴리오 사이트입니다.

**Live —** https://sonjh7874-ctrl.github.io/portfolio/

VOC·행동 데이터 분석부터 서비스 콘셉트 설계까지 다룬 프로젝트를 정리했습니다. 엔터·미디어·마케팅 분야의 서비스 기획을 지향합니다.

---

## 수록 프로젝트

### 01. LG LINK — 가전을 넘어 가정을 만나다

ThinQ 앱과 LG 스마트 TV를 활용한 가족 소통 서비스 BX 기획.

- 역할: 팀장 (5인)
- 분야: BX 기획
- 성과: 장려상
- 상세: [link.html](./link.html)

### 02. LG LILO — VOC 127,675건이 만든 서비스

순환형 가전 구독 승계 CX 서비스 기획. VOC 127,675건을 분석해 문제를 정의하고 서비스 콘셉트로 옮겼습니다.

- 역할: 데이터 분석·팀 운영 (4인)
- 분야: 데이터 분석
- 성과: 우수상
- 상세: [lilo.html](./lilo.html)

## 기술 구성

프레임워크 없는 정적 사이트입니다.

- HTML / CSS / Vanilla JavaScript
- 폰트: Pretendard, IBM Plex Mono (CDN)
- 배포: GitHub Pages (`main` 브랜치 root)

빌드 과정이 없어 저장소의 파일이 그대로 배포됩니다.

## 폴더 구성

```
portfolio/
├── index.html          메인 (Hero · About · Work · Contact)
├── link.html           LG LINK 상세
├── lilo.html           LG LILO 상세
└── assets/
    ├── css/style.css   디자인 시스템 (색·타이포·레이아웃)
    ├── js/main.js      내비게이션, 스크롤 애니메이션, 이미지 확대
    ├── img/            도표·목업 이미지
    └── resume.pdf      이력서
```

## 로컬에서 보기

별도 빌드나 설치 없이 `index.html`을 브라우저로 열면 됩니다. 폰트가 CDN에서 로드되므로 인터넷 연결이 필요합니다.

VS Code를 쓴다면 Live Server 확장을 설치하고 `index.html`에서 우클릭 → *Open with Live Server*.
